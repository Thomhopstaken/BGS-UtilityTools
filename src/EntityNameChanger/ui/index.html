Entity Name Changer

Rename entities and their associated elements

How does this tool work?

Read before using!

Errors on microflow activities like retrieves will cause the renaming to fail

Do not cancel an attempt via the dialog message! It will cause a lot of errors.

Updating all the variable usages can take a while, especially when the entity is used a lot. Do not cancel

If a lot of non-sensical errors remain after a rename, press f4 to refresh.

this is extension (and the ExtensibilityAPI) is still in beta, expect some bugs.

Which elements of the model will be renamed?
  • The chosen entity and its associations
  • All microflow holding parameters or variables instances of entity and containing entity name in name.
  • Pages(when selected) where the name contains the entityName
which microflow activities will be renamed?
The following counts for all stated activities, the resulting variable must be an instance of the chosen entity and have the entity name in its name.
  • Parameters
  • Create actions
  • Retrieve actions (database and association)
  • Create list actions
  • List operations (excluding filter by expression and range)
  • microflow call actions
Why are not all elements updated?
The current iteration of the ExtensibilityAPI does not give enough access (or no access at al) too accurately rename other elements than the ones renamed at this moment. This counts for action activities and loops too.
