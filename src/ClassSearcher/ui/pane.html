BGS-UtilityTools - ClassSearcher

Find the elements that use a CSS class in pages, snippets and layouts

One class name, exact and case-sensitive. A leading dot is ignored.
Results

    How does this tool work?

    What is searched
    • The Class field of every widget, layout grid row and column, table cell and container region.
    • Dynamic classes: the class names inside quoted text, e.g. if $currentObject/IsUrgent then 'card--highlight' else ''
    • Pages, snippets, layouts, building blocks and page templates in your own modules.

    Matching is exact and case-sensitive, like CSS: card doesn't find card--highlight or Card.

    What isn't found
    • Class names built from parts in an expression, e.g. 'card--' + $Status
    • Classes added by design properties
    • Classes set in pluggable widget properties, such as a dynamic cell class in Data grid 2
    • Marketplace modules and System
    • Classes in your theme's SCSS or in JavaScript
    Opening a result

    Click a document to open it in Studio Pro. Click an element to open its document and select the element.

    Results don't follow your edits. Search again after you change a page.

    Known limitations

    This tool is built on Mendix's Extensibility API for Studio Pro 11.12. The API is in beta, so behaviour can change between Studio Pro versions.
